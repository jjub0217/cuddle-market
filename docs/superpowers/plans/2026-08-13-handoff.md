## 오늘 겪은 함정 (되풀이하지 말 것)

**여덟 가지가 시험·타입체크·린트를 다 통과하고 눈으로만 드러났다.**

```
누르자마자 붙잡기    setPointerCapture 는 **뒤따르는 click 의 대상을 바꾼다.**
                     확대를 끄려던 누름이 창을 닫았다. 붙잡기는 움직인 뒤에 건다
                     → CLAUDE.md 「게이트」에 적어 뒀다

리액트 onWheel       passive 로 달려서 preventDefault 가 무시된다.
                     요소에 직접 { passive: false } 로 달아야 한다

맥의 확대 입력 둘     두 손가락 벌리기 = ctrl+휠 · ⌘+두 손가락 = metaKey.
                     ctrl 만 받았더니 ⌘ 로 하는 사람에게는 아무 일도 안 일어났다

max-h-full           **상한만 정한다. 원본보다 크게는 안 만든다.**
                     600×800 사진이 큰 모니터 가운데 조그맣게 떴다

두 상태의 크기 순서   맞춤을 키웠더니 「크게」가 더 작아져 **벌릴수록 작아졌다.**
                     둘 중 하나를 손대면 순서부터 확인할 것

onClose 를 의존성에   쓰는 쪽이 그 자리에서 만들어 넘기면 렌더마다 새 함수가 된다.
                     효과가 매번 다시 돌며 기록을 넣었다 뺐다 해서
                     **뒤로가기가 홈까지 밀려났다**

Modal 안 안전영역     시험에 SafeAreaProvider 감싸개가 필요하다
                     → mobile/AGENTS.md 함정표에 적어 뒀다

제스처 안 바깥 함수   UI 스레드에서 일반 함수를 부르면 죽는다. 숫자로 담아 쓴다
                     → 같은 곳에 적어 뒀다
```

**머지 순서도 한 번 걸렸다.** 쌓아 올린 PR 을 base PR 보다 늦게 머지해서 develop 에
2·3단계가 안 들어갔다. PR 을 하나 더 만들어 해결했다(#908) → `CLAUDE.md` 「머지 워크플로우」.
