## 🔴 다음 세션 첫 일 — 「판매중」을 서버가 거르게 (이슈 없음, 만들면서 시작)

웹의 「판매중」 토글이 **반쪽**이다. 서버가 안 걸러 줘서 **받아온 20개 중에서 화면이 남긴다.**

```js
// src/features/home/components/product-section/ProductsSection.tsx:67
if (!onlyOnSale) return products
return products.filter((p) => p.tradeStatus === 'SELLING' || p.tradeStatus === null)
```

**서버는 이미 준비돼 있다.** 운영 서버에서 직접 재 봤다(2026-08-20).

```
조건 없음                  전체 61개
tradeStatuses=SELLING      55개   ← 판매중 + 판매요청(tradeStatus 가 NULL)
tradeStatuses=COMPLETED     6개
55 + 6 = 61  ✅
```

⚠️ **`SELLING` 을 물으면 NULL 도 함께 온다.** 판매요청 상품은 거래 상태가 없어서, 그렇게
안 하면 「판매중만 보기」를 켤 때 판매요청이 통째로 사라진다. 지금 웹 화면이
`=== 'SELLING' || === null` 로 걸러 온 것과 같은 규칙이다(백엔드 커밋 778fc6c).

**정할 것 — 범위**

```
A  웹만 먼저   onlyOnSale 을 서버 쿼리(tradeStatuses)로 바꾼다. 작다
B  웹 + 앱     앱에는 그 토글이 **아직 없다.** 같이 넣는다
```

⚠️ B로 가면 **앱에서 토글을 어디에 둘지** 정해야 한다. 후보는 세부 필터 시트의 「상품 상태」
위인데, **그 시트는 [적용]을 눌러야 반영**되는 방식이라 토글의 즉시성과 결이 다르다.
툴바(`[전체][판매][판매요청] [⚙] [최신순 ▾]`)는 390px 에서 이미 빽빽해 자리가 마땅치 않다.

⚠️ **이슈는 착수할 때 만든다.** 백엔드 일로는 프론트 이슈도 새로 만들지 않는다는 규칙이
있어(2026-08-19 정정), 이번에는 **프론트 작업이 실제로 시작될 때** 만들기로 했다.

## ⭐ 오늘 크게 데인 것 — 다음에 또 밟기 쉽다

### 상태가 둘이면 **둘 다** 잰다

목록 서랍을 **열린 상태만** 재고 「됐다」고 했다. 닫힌 상태에서 머리글이 탭바를 덮고
있었고, 사용자 스크린샷으로 잡혔다.

```
translate-y-full 은 **자기 높이만큼만** 내려간다.
바닥에서 띄워 둔 요소는 그 띄운 만큼이 남는다 → 닫힘 이동값 = 높이 + 띄운 값
```

### 앱 화면은 내가 못 본다 — 스크린샷 한 장으로 단정하지 말 것

「마지막 항목이 잘린다」는 사진을 보고 **탭바가 덮는다**로 단정해 여백을 더했다. 실제로는
**시트를 끝까지 안 올린 상태**였다. 문제 자체가 없었고 내 「고침」이 아래를 통째로 비웠다.
되돌렸다(#979 닫음).

→ 앱 문제는 먼저 되묻는다: **마지막 항목 이름이 무엇인가 · 끝까지 펼친 상태인가.**

### 「앱처럼」이라고 하면 앱 파일을 **열어서 값을 가져온다**

⚙ 단추와 정렬 단추를 웹 감각으로 만들어 알약 테두리를 둘렀다. 앱에는 테두리가 없다.
지어내지 말고 `product-list-toolbar.tsx` 의 실제 값(32×32 · height 32 · gap 2 · 글자 13)을 옮긴다.

### 확인을 부탁하기 전에 **브랜치부터 맞춘다**

지도 수정을 `fix/969` 에 두고 `feat/970` 브랜치인 채로 확인을 부탁드렸다. 사용자는
고치기 전 화면을 보고 「안 고쳐졌다」고 했다. 개발 서버가 어느 브랜치를 보는지 먼저 맞춘다.

### 레이아웃에 `useSearchParams()` 를 넣으면 **빌드가 깨진다**

`(main)/layout.tsx` 에 넣었더니 그 레이아웃을 쓰는 화면이 전부 서버에서 안 그려져
`/auth/login` 정적 빌드가 실패했다. 그런 판단은 **그 화면 안에서** 한다.

### JSX 주석을 `return (` 바로 뒤에 두지 않는다

오늘도 두 번 더 밟았다(누적 다섯 번). 주석은 **`return` 위에 `//` 로**.
