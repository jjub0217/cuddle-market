```
                     flexGrow 가 살아나 줄이 목록과 자리를 나눠 갖고 **글자 아래가 잘린다.**
                     → 겹을 **조각 안으로** 넣었다(#946). 이제 어디에 붙여도 안 밟힌다

⭐ 색은 「기준 통과」가  고른 탭이 **오히려 작아 보였다.** 재 보니 착시가 아니었다 —
   아니라 「옆과 견줘」  accent #825500 은 흰 배경 대비 6.46:1 인데
                     안 고른 탭 회색 #4B5563 은 7.56:1 이다. **고른 쪽이 더 흐리다.**
                     굵은 한글은 획이 안쪽으로 두꺼워져 속이 좁아지니 더 작아 보인다.
                     → 고른 탭만 15 → 16. **줄 높이를 양쪽에 못 박아야** 안 들썩인다
                     (AGENTS.md 「색을 고를 때」에 같은 함정이 이미 있다)

⭐ 화면 두 개를 오가면  검색 화면 → 목록으로 갈 때 **검색 줄이 둘 나란히** 보였다.
   같은 것이 둘 보인다  둘 다 검색 줄을 그리는 화면이라서다. 표준 전환이라 「정상」인데
                     커뮤니티는 결과를 **같은 화면**에 그려서 어색하다.
                     → ① replace 를 dismissTo 로 (새 화면을 안 만들고 걷어낸다)
                       ② 그 화면만 `animation: 'none'` — 검색 줄 자리가 같아서
                          **줄은 제자리에 남고 아래만 바뀐 것처럼** 보인다

⚠️ 주소값은 배열로     `useLocalSearchParams` 는 같은 열쇠가 여러 번 실리면
   올 수 있다          (`?keyword=a&keyword=b`) **string[] 을 준다.** 우리 코드는 늘
                     하나를 넣지만 **딥링크로는 누구나 그런 주소를 만든다.**
                     타입 단언으로 덮지 말고 첫 값만 집는다 — 덮어 둔 자리는 조용히 터진다

⚠️ 이 맥에는 `timeout`  시험이 안 끝나는 것 같아 `timeout 240 npx jest` 로 감쌌더니
   명령이 없다         **명령을 못 찾아 아무것도 안 돌았다.** 출력이 없는 것을 보고
                     「계속 멈춰 있다」로 잘못 읽었다. 오래 걸리면 도구 시간제한을 늘려라

⚠️ jest 일꾼이 남는다   시간 초과로 끊긴 실행의 일꾼 프로세스가 살아남아 다음 실행을
                     붙잡는다. 그것만 골라 죽인다 — **Metro·웹 dev 를 같이 죽이지 마라**
                     pkill -f "jest-worker@.*processChild.js"
```

## 판(tmux) 병렬 — 오늘 최대 6개

```
Agent(name: '이름')         판이 갈라진다 ✅
Agent(isolation:worktree)   백그라운드. 판이 안 갈라진다 ❌

⚠️ 판들이 **같은 작업 트리**를 쓴다. 브랜치를 따로 못 준다
   → 한 트리에서 작업시키고 **리드가 브랜치별로 갈라 담는다**
   → 겹치는 파일이 없게 「저 폴더는 건드리지 마라」를 못 박아야 한다

⚠️ 백엔드 저장소에 쓸 때는 **권한 승인이 필요하다** — 판이 조용히 멈춘다.
   빈 알림만 오므로 `git status` 로 실제 진행을 확인할 것

⚠️ 서버 판(Metro·웹 dev)을 죽이지 않게 **프로세스로 가려낸다.**
   오늘 두 번 잘못 죽였다 (로그 글자만 보고 판단하면 틀린다)

⭐ **판의 보고가 리드에게 안 올 수 있다.** 오늘 두 판 다 그랬다 — 일은 다 해 놓고
   빈 대기 알림만 보냈다. 기다리지 말고 **직접 읽어라**:
     tmux capture-pane -p -S -120 -t claude:0.<번호>   판에 찍힌 보고를 그대로 본다
     git diff / git status                            판이 실제로 고친 것을 본다
   ⚠️ 어차피 **커밋 전에 리드가 diff 를 봐야 한다.** 보고를 못 받아도 막히지 않는다

⚠️ 판이 **Claude Code 첫 설정 화면**(auto mode)에 걸려 멈출 수 있다. 그 화면이 뜨면
   키보드가 그 판에 가 있어야 눌린다:
     Ctrl-b 뗀 뒤 q → 번호 → 그 판으로 이동 · Esc 로 취소 · Ctrl-b 뗀 뒤 o 로 복귀
   리드가 대신 보낼 수도 있다: `tmux send-keys -t claude:0.<번호> Escape`
   ⚠️ 「셸 기록도 훑기」는 켜지 마라 — 토큰·비밀번호를 붙여넣은 줄이 남아 있을 수 있다
```

⚠️ **되돌려야 하는 명령을 한 줄로 잇지 마라.** 오늘 `git stash push … && jest ; git stash pop`
