### 배포 뒤 확인 (순서대로)

```
1. 표가 생겼는지
   SHOW TABLES LIKE 'view_logs';
   SHOW CREATE TABLE view_logs;      -- uk_viewer_target_date 가 보여야 한다

2. ⭐ 상품 조회수가 처음으로 오르는지 — 이번 작업의 알맹이
   A 계정으로 B 의 상품 상세를 연다   → 0 → 1
   뒤로 갔다 다시 들어간다           → 그대로 1
   또 들어간다                      → 그대로 1

3. 커뮤니티 글도 같은지
   A 계정으로 B 의 글을 연다 → +1 · 다시 → 안 오름 (예전엔 계속 올랐다)

4. 안 세야 하는 것이 그대로인지 (안 건드렸다)
   내 상품·내 글을 내가 봄 → 안 오름 · 로그아웃 상태 → 안 오름

5. 한국시간 자정을 넘긴 뒤 같은 것을 다시 열면 +1 (아침 9시가 아니라 자정이어야 맞다)
```

**배포 전 상태를 재 뒀다** — 상품 60개 전부 0. 아래로 훑으면 배포 뒤 값이 떠야 한다.

```bash
curl -s "https://cmarket-api.duckdns.org/api/products/search?page=0&size=60" \
| python3 -c "import sys,json; d=json.load(sys.stdin)['data']['content']; \
print('0 아닌 것:', sum(1 for p in d if p.get('viewCount')), '/', len(d))"
```
