## 판(tmux) 병렬 — 오늘 최대 6개

```
Agent(name: '이름')         판이 갈라진다 ✅
Agent(isolation:worktree)   백그라운드. 판이 안 갈라진다 ❌

⚠️ 판들이 **같은 작업 트리**를 쓴다. 브랜치를 따로 못 준다
   → 한 트리에서 작업시키고 **리드가 브랜치별로 갈라 담는다**
   → 겹치는 파일이 없게 「저 폴더는 건드리지 마라」를 못 박아야 한다

⚠️ 백엔드 저장소에 쓸 때는 **권한 승인이 필요하다** — 판이 조용히 멈춘다.
   빈 알림만 오므로 `git status` 로 실제 진행을 확인할 것

⚠️ 서버 판(Metro·웹 dev)을 죽이지 않게 **프로세스로 가려낸다.**
   오늘 두 번 잘못 죽였다 (로그 글자만 보고 판단하면 틀린다)

⭐ **판의 보고가 리드에게 안 올 수 있다.** 오늘 두 판 다 그랬다 — 일은 다 해 놓고
   빈 대기 알림만 보냈다. 기다리지 말고 **직접 읽어라**:
     tmux capture-pane -p -S -120 -t claude:0.<번호>   판에 찍힌 보고를 그대로 본다
     git diff / git status                            판이 실제로 고친 것을 본다
   ⚠️ 어차피 **커밋 전에 리드가 diff 를 봐야 한다.** 보고를 못 받아도 막히지 않는다

⚠️ 판이 **Claude Code 첫 설정 화면**(auto mode)에 걸려 멈출 수 있다. 그 화면이 뜨면
   키보드가 그 판에 가 있어야 눌린다:
     Ctrl-b 뗀 뒤 q → 번호 → 그 판으로 이동 · Esc 로 취소 · Ctrl-b 뗀 뒤 o 로 복귀
   리드가 대신 보낼 수도 있다: `tmux send-keys -t claude:0.<번호> Escape`
   ⚠️ 「셸 기록도 훑기」는 켜지 마라 — 토큰·비밀번호를 붙여넣은 줄이 남아 있을 수 있다
```

⚠️ **되돌려야 하는 명령을 한 줄로 잇지 마라.** 오늘 `git stash push … && jest ; git stash pop`
을 한 줄로 쳤다가 중간에 멈춰서 **되돌리는 쪽이 안 돌았고, 고침이 stash 에 갇혔다.**
