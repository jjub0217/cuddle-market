# §2. ⭐⭐ 오늘 가장 큰 배움 — **「고쳤는데 안 바뀐다」는 단서다**

세 번 통했다. 셋 다 **내가 넣은 것이 정말 들어갔는지 확인한 뒤**, 들어갔는데도 그대로라서 방향을 틀었다.

| 무엇 | 내 추측 | 확인한 것 | 진짜 원인 |
|---|---|---|---|
| 아이콘이 64×80 | flex 가 눌렀다 → `shrink-0` | `flexShrink: 0` **이 들어갔는데도** 64×80 | 테일윈드의 `max-width: 100%` |
| 프로필 카드가 안 붙음 | `sticky` 를 붙이면 된다 | 붙였는데 안 먹음 | `<aside>` 의 `h-fit` → 미끄러질 여백 0 |
| jest 가 안 끝남 | 두 파일만 고치면 된다 | 고쳤는데 **게이트 경고 그대로** | 같은 문제 파일이 셋 더 있었다 |

## 왜 그런가 — CSS 크기는 **단계**가 있다

```
① 지정한 값      width: 80px       ← w-20
② max 로 깎기    max-width: 100%   ← 부모가 64 → 80을 64로 깎는다   ★ 여기서 졌다
③ min 으로 밀기  min-width/height  ← 최종 승자

flex 의 shrink 는 ① 단계 이야기(줄이 모자랄 때 줄일까 말까)
max-width 는 ② 단계 — **단계가 다르니 shrink 로는 절대 못 막는다**
```

세로가 80 그대로였던 것도 여기서 설명된다. `max-height` 는 안 걸려 있으니까.
**한 쪽만 깎여서** Next 가 「가로세로 중 하나만 바뀌었다」 경고를 띄웠다.

같은 뿌리의 사건이 어제 둘 더 있었다.

```
min-h-screen 을 안 지웠으면   h-[calc(...)] 로 높이를 정해도 min-height 가 이겨(③단계)
                             페이지가 그대로 길어진다
min-h-0 을 안 넣으면          flex 자식은 min-height: auto 가 기본이라 내용보다 못 줄어든다
                             → 안쪽에 overflow-y-auto 를 줘도 스크롤이 안 생긴다
```

**⚠️ 그래서 이렇게 한다:** "분명 고쳤는데 화면이 그대로"일 때 **두 번 시도하기 전에**
「내가 넣은 것이 정말 들어갔나」부터 본다. 들어갔는데도 그대로면 **원인이 딴 데 있다.**
크기 문제는 `min-*`/`max-*` 를 먼저 의심한다.


## 왜 굳나 — **경고 문구가 범인을 안 가리킨다**

```
「A worker process has failed to exit gracefully」
   ← 어느 파일인지·무엇이 남았는지 한 마디도 안 한다
   → 읽는 사람에게는 「도구가 원래 좀 그런가 보다」로 들린다
   → 도구 탓으로 넘어가고, 넘어간 것이 문서에 적히며 **「사양」이 된다**
```

**잡음이 제도로 굳으면 그 뒤로 오는 진짜 신호도 같이 묻힌다.**

## 잰 결과

```
앱 게이트 경고   1건 → **0건**
한 파일 실행     40초가 지나도 안 끝남 → **2.67초**
웹 콘솔 경고     8건 → **0건** (그리고 그건 진짜 아이콘이 찌그러진 것이었다)
```

**⚠️ 그래서 이렇게 한다:** 경고 개수를 **0으로 유지하는 것 자체가 기능**이다. 0이어야 1이 눈에 띈다.
그리고 **「원래 그렇다」가 적힌 문서를 보면 의심부터** 한다 — 오늘 그게 틀렸다.

# §4. ⭐ 적어 두는 것과 따르게 하는 것은 다른 일이다

jest 매달림의 함정은 **`mobile/AGENTS.md` 44줄에 이미 적혀 있었다.** 증상·원인·고치는 법에
「**2026-08-17 에 3분씩 두 번 날렸다**」는 손해 기록까지 붙어 있었다. **그런데도 다섯 파일이 안 따랐다.**

```
문서   처음 들어올 때 한 번 읽는다        → 그 뒤로는 안 본다
코드   시험 파일을 새로 만들 때마다 쓴다   → 그 순간에 문서를 다시 열 이유가 없다
```

규칙이 **글로만** 있으면 어기는 순간에 아무도 막지 않는다.

```
사다리 — 위로 갈수록 세다
  ① 문서에 적는다                    ← 여기 있었다. 다섯 파일이 그냥 지나갔다
  ② 리뷰에서 본다                     사람이 매번 기억해야 한다
  ③ 게이트가 막는다                   경고 0건을 잠근다
  ④ 함정을 만들 수가 없게 한다  ★      시험용 QueryClient 만드는 함수 하나를 두고
                                     새로 만드는 길을 아예 없앤다
```

**이 저장소는 CSS 에서는 이미 답을 알고 있다** — `constants/ui.ts` 가 그 증거다.
「`px-*` 를 손으로 적지 말고 이것을 써라」, z 값도 숫자 대신 `Z_INDEX` 상수.
**손으로 적을 기회 자체를 없앤 것**이다. 시험 설정만 아직 그 단계에 안 왔다.

⚠️ **오늘 `probe/` 와 머지 스크립트가 ③·④ 로 올린 첫 시도다**(#1056).
