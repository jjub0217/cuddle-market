## ⭐ 오늘 가장 크게 배운 것

### 「어정쩡해 보인다」의 정체는 재 보면 나온다

사용자가 「어정쩡하다」고 했을 때 눈으로 고치려 들지 말 것. 재 보니 원인이 한 줄이었다.

```
띠(히어로) 높이는 어느 폭에서나 400px 인데 그림만 작아진다
  721px    그림 192 → 위로 208px 이 텅 빔
  1024px   그림 360 → 위로  40px
```

### 세 안을 찍어서 고르게 하는 게 빨랐다

말로 설명하는 것보다 **실제 화면 3장 × 3폭**을 찍어 `public/preview/` 에 두고
`http://localhost:3000/preview/` 로 보게 하는 편이 결정이 빨랐다. 두 번 그렇게 했다.

```js
// 코드를 안 고치고 CSS 만 덮어써서 찍는다
await page.evaluate((css) => { const s = document.createElement('style'); s.textContent = css; document.head.appendChild(s) }, css)
await (await page.$('section[aria-label="히어로"]')).screenshot({ path: … })
```

⚠️ 끝나면 `public/preview/` 와 `public/diag.html` 을 **반드시 지운다.** 배포에 섞인다.

### 값 넷은 서로 묶여 있다 — 하나만 고치면 어긋난다

```
① 띠 높이와 top-%      글자 칸이 띠 높이의 몇 %에서 시작한다
                      → **띠를 32 키워도 단추 아래는 11 밖에 안 는다**
② 헤더가 덮는 높이      홈에서 헤더는 히어로 위에 투명하게 뜨고 아래끝이 72px
                      → 글자를 더 올리면 헤더 뒤로 들어간다 (지금 제목 위끝 87~94)
③ 그림 폭은 안 변한다   높이로 크기가 정해진다(h-90 이면 늘 474px)
                      → 띄우는 값도 % 가 아니라 **고정 px** 이어야 한다
④ w-full 은 여백을 모른다  `left` 를 안 준 절대배치 칸은 **여백 안쪽에서 시작**하는데
                      폭은 컨테이너 전체를 받는다 → 오른쪽으로 삐져나가
                      **1024~1280 에서 페이지가 가로로 밀렸다**(scrollWidth 1038 vs 1024)
```

### 내가 두 번 헛짚었다 — 둘 다 재서 잡았다

```
1  아이패드에서 히어로가 세로로 쌓여 보였다
   → 「기기에서 반응형 CSS 가 안 먹는다」고 의심했는데 **낡은 탭이었다.**
     새로고침하니 멀쩡했다. 사파리 17.14 는 정상이다

2  그걸 확인하려고 만든 진단 페이지가 **틀린 시험이었다**
   → `@layer` 안의 규칙은 **밖의 규칙에 무조건 진다**(우선순위가 아니라 층이 아래).
     `.box{background:#eee}` 를 층 밖에 둬서 어느 브라우저에서도 회색이 이겼다.
     **맥 크롬으로 같은 페이지를 돌려 보고서야** 알았다
```

⚠️ **기기에서만 이상하면 먼저 새로고침**(탭을 닫고 새 탭). 그다음에 브라우저를 의심한다.
⚠️ **진단 도구를 만들면 정상 환경(맥 크롬)에서 먼저 돌려 본다.** 도구가 틀리면 진단이 틀린다.

### JSX 주석을 `return (` 바로 뒤에 두면 화면이 통째로 안 그려진다

**오늘 두 번 그랬다.** 둘 다 재다가 「히어로 없음」이 찍혀서 잡았다 — 눈으로만 봤으면
넘어갔을 수 있다.

```jsx
return (
  {/* 주석 */}      ← ✗ 파싱 오류. 뿌리가 둘이 된다
  <section …>
)
return (
  // 주석          ← ✓ 이건 된다
  <section …>
)
```

## 아직 정하지 못한 것

### 웹을 어디까지 앱처럼 만들 것인가

사용자가 던진 물음이고 **답을 안 냈다.** 지금은 640~1023 에서
**모바일 헤더 + 하단 탭바 + 수평 히어로**가 섞여 있다. 의도한 것이지만,
「태블릿은 앱처럼」으로 방향을 잡으면 여기가 제일 먼저 손댈 자리다
(히어로 수평 전환을 640 → 1024 로 올리면 1024 하나로만 갈린다).

### 세부 필터가 처음부터 펼쳐져 있는 것

```js
// src/features/home/Home.tsx
const [isDetailFilterOpen, setIsDetailFilterOpen] = useState(true)
```

좁은 화면에 「필터」 여닫는 단추가 있는데도 기본이 열림이라 어정쩡하다. **안 정했다.**
