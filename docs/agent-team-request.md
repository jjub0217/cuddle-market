# agent team 모드 활용

이 문서는 agent team 를 활용한 요청사항을 정리한 문서입니다.

---

## 상품관리

### 1. 유형

삽니다 뱃지 컬러 #FFF7ED 으로 적용.<br>
팝니다 뱃지 컬러 #7BA5D6 으로 적용.<br>

### 2. 거래 상태

#### 삽니다

삽니다 상품의 거래 상태는 요청중 / 요청완료 로 설정.<br>
요청중 뱃지 컬러 #DCFCE7 으로 적용.<br>
요청완료 뱃지 컬러 #F3F4F6 으로 적용.<br>

#### 팝니다

팝니다 상품의 거래 상태는 판매중 / 예약중 / 판매완료 로 설정.<br>
판매중 뱃지 컬러 #DCFCE7 으로 적용.<br>
판매완료 뱃지 컬러 #F3F4F6 으로 적용.<br>
예약중 뱃지 컬러 #FEF9C3 으로 적용.<br>

### 3. 필터 드롭다운

필터 드롭다운 을 클릭한 이후에 펼쳐진 옵션 리스트에서 선택이 된 옵션들에는 맨 오른쪽에 체크 아이콘 표시.

### 4. 상품 상세정보 모달

- 회원관리 > 유저관리의 사용자 상세정보 모달과 같은 레이아웃과 디자인.
- 타이틀은 "상품 상세 정보"
- 상품의 대표 이미지가 크게 보이고 그 아래에 서브 이미지들을 가로 정렬로 조그맣게 표시.<br>
  그 아래에 상품 id 이라는 라벨과 값 을 세로 정렬로.<br>
  그 오른쪽에 닉네임이라는 라벨과 값을 세로 정렬로.<br>
  그 아래에 상품명이라는 라벨과 값을 세로 정렬로.<br>
  그 아래에 지역이라는 라벨과 값을 세로 정렬로.<br>
- 대표이미지의 오른쪽에 상품 설명이라는 라벨과 상품 설명이 세로 정렬로.
- 상품 설명 아래로 거래상태라는 라벨과 값을 세로 정렬로.
- 거래상태의 오른쪽에 상품 상태라는 라벨과 값이 세로 정렬로.
- 상품 상태 아래에 유형이라는 라벨과 값을 세로 정렬로.
- 유형의 오른쪽에 가격이라는 라벨과 값을 세로 정렬로.
- 가격 아래에 조회수 라는 라벨과 값을 세로 정렬로.
- 조회수 오른쪽에 찜갯수 라는 라벨과 값을 세로 정렬로.
- 찜갯수 아래에 작성일시 라는 라벨과 값을 세로 정렬로.
- 작성일시 오른쪽에 수정일시 라는 라벨과 값을 세로 정렬로.
- 거래상태 라벨의 값과 상품 상태 라벨의 값, 유형 라벨의 값은 테이블에 잇는 뱃지와 같은 디자인으로 적용.
- 회원관리 > 유저관리 사용자 상세정보 모달처럼 맨 아래 오른쪽에 버튼이 있는데 삭제 버튼만 있도록.
- 해당 삭제 버튼을 클릭하면 회원관리 > 유저관리 사용자 상세정보 모달에서 삭제하기 버튼을 누르면 보이는 모달처럼, 컨펌 모달이 보이도록 해주세요.<br>
  해당 컨펌 모달에는 "상품 삭제 확인" / "삭제 시 해당 상품과 관련된 모든 데이터가 즉시 삭제되며 되돌릴 수 없습니다." 이라는 텍스트가 보이도록 해주세요.

## 커뮤니티 관리

어드민 페이지 사이드바 메뉴에서 상품관리 메뉴 아래에 보이도록 적용.

### 테이블

- 테이블의 컬럼명은 게시글 id, 유형, 제목, 닉네임, 작성일시, 수정일시 순서로 적용.
- 테이블의 위에 회원관리 > 유저관리 처럼 검색창과 필터 드롭다운이 있어야 한다.
- 필터 드롭다운은 게시글 유형 이라는 라벨과 드롭다운, 정렬 이라는 라벨과 드롭다운 표시.
- 게시글 유형의 옵션리스트에는 전제/질문있어요/정보공유 적용.
- 정렬 옵션리스트에는 전체/최신순/오래된 순으로 적용.

### 게시글 상세정보 모달

- 상품관리의 상세정보 모달과 같은 2컬럼 레이아웃으로 적용.
- 왼쪽 컬럼: 대표 이미지 → 서브 이미지(4칸, 빈 칸은 placeholder) → 게시글 ID/닉네임 → 제목 → 작성일시/수정일시
- 오른쪽 컬럼: 게시글 내용(스크롤 가능) → 유형 뱃지 → 댓글 목록(개수 표시)
- 댓글 목록은 하나의 border 컨테이너 안에 divide-y로 구분.
- 댓글(depth 0)과 대댓글(depth 1)이 있으며, 대댓글은 왼쪽 들여쓰기로 구분.
- 각 댓글에 개별 삭제 버튼(빨간색 휴지통 아이콘) 표시.
- 댓글 삭제 시 별도 컨펌 모달 표시.
- 하단에 닫기 + 삭제 버튼. 삭제 버튼은 해당 게시글을 삭제하는 버튼.

## 신고관리

- 어드민 페이지 사이드바 메뉴에서 커뮤니티 관리 메뉴 아래에 보이도록 적용.
  1depth 로 적용.
- 1depth 메뉴들로 유저신고, 판매상품 신고, 판매요청 상품 신고, 커뮤니티 신고 순서로 적용.

### 유저신고

#### 테이블

- 테이블의 컬럼명은 신고 id, 신고자, 신고 대상자 닉네임, 신고 항목, 신고일자 순서로 적용.
- 테이블의 위에 검색창(placeholder: "신고자 또는 신고 대상자 닉네임 검색...")과 필터 드롭다운이 있어야 한다.
- 필터 드롭다운은 신고 항목 이라는 라벨과 드롭다운, 정렬 이라는 라벨과 드롭다운 표시.
- 신고 항목의 옵션리스트에는 현재 프로젝트의 신고항목들로 적용.
  정렬 옵션리스트에는 전체/최신순/오래된 순으로 적용.

#### 유저 신고 정보 모달

- 회원관리 > 유저관리의 사용자 상세정보 모달과 같은 레이아웃과 디자인.
  타이틀은 "유저 신고 정보"
- 신고 id 이라는 라벨과 값 을 세로 정렬로.
- 신고 id 오른쪽에 신고자 닉네임이라는 라벨과 값을 세로 정렬로.
- 신고자 닉네임 아래에 신고자 대상자 닉네임 이라는 라벨과 값을 세로 정렬로.
- 신고자 대상자 닉네임 오른쪽에 신고항목 이라는 라벨과 값을 세로 정렬로.
- 신고항목 아래에 신고일자 라는 라벨과 값을 세로 정렬로.
- 신고일자 아래에 신고 상세 사유가 있다면, 신고 상세 사유 라벨과 값을 세로 정렬로 적용(신고 상세 사유는 선택항목입니다. 현재 프로젝트를 분석, 확인하면 알수 있습니다.)
- 신고 상세 사유 아래에 첨부 이미지 라는 라벨과 이미지 최대 3개가 가로 정렬로 보여야 합니다.(신고 이미지는 선택항목입니다. 현재 프로젝트를 분석, 확인하면 알수 있습니다.)
- 하단에 닫기 + 정지 버튼. 정지 버튼 클릭 시 "유저 정지 확인" 컨펌 모달 표시. (신고된 유저 계정을 정지하는 버튼)

### 판매상품 신고

#### 테이블

- 테이블의 컬럼명은 신고 id, 이미지, 상품명, 신고자, 판매자, 신고 항목, 신고일자 순서로 적용.
- 테이블의 위에 검색창(placeholder: "상품명 검색...")과 필터 드롭다운이 있어야 한다.

#### 판매상품 신고 정보 모달

- 신고관리 > 유저신고의 유저 신고 정보 모달과 같은 레이아웃과 디자인.
- 유저신고의 신고 정보 모달에서 신고 대상자 닉네임 보인다면, 판매상품 신고 정보 모달에서는 판매자 닉네임으로 적용.
- 판매자 닉네임과 신고항목위에 상품명이라는 라벨과 값이 세로로 정렬.
- 판매상품 신고항목 옵션리스트는 현재 프로젝트를 분석, 확인하면 알수 있습니다.
- 신고 상세 사유 아래에 첨부 이미지 라는 라벨과 이미지 최대 3개가 가로 정렬로 보여야 합니다.(신고 이미지는 선택항목입니다. 현재 프로젝트를 분석, 확인하면 알수 있습니다.)
- 하단에 닫기 + 삭제 버튼. 삭제 버튼 클릭 시 "상품 삭제 확인" 컨펌 모달 표시. (신고된 상품을 삭제하는 버튼)

### 판매요청 상품 신고

#### 테이블

- 테이블의 컬럼명은 신고 id, 이미지, 상품명, 신고자, 요청자, 신고 항목, 신고일자 순서로 적용.
- 테이블의 위에 검색창(placeholder: "상품명 검색...")과 필터 드롭다운이 있어야 한다.

#### 판매요청 상품 신고 정보 모달

- 신고관리 > 유저신고의 유저 신고 정보 모달과 같은 레이아웃과 디자인.
- 유저신고의 신고 정보 모달에서 신고 대상자 닉네임 보인다면, 판매요청 상품 신고 정보 모달에서는 요청자 닉네임으로 적용.
- 요청자 닉네임과 신고항목위에 상품명이라는 라벨과 값이 세로로 정렬.
- 판매요청 상품 신고항목 옵션리스트는 현재 프로젝트를 분석, 확인하면 알수 있습니다.
- 신고 상세 사유 아래에 첨부 이미지 라는 라벨과 이미지 최대 3개가 가로 정렬로 보여야 합니다.(신고 이미지는 선택항목입니다. 현재 프로젝트를 분석, 확인하면 알수 있습니다.)
- 하단에 닫기 + 삭제 버튼. 삭제 버튼 클릭 시 "상품 삭제 확인" 컨펌 모달 표시. (신고된 요청 상품을 삭제하는 버튼)

### 커뮤니티 신고

#### 테이블

- 테이블의 컬럼명은 신고 id, 게시글 유형, 신고자, 제목, 작성자, 신고 항목, 신고일자 순서로 적용.

#### 커뮤니티 신고 정보 모달

- 하단에 닫기 + 삭제 버튼. 삭제 버튼 클릭 시 "게시글 삭제 확인" 컨펌 모달 표시. (신고된 게시글을 삭제하는 버튼)
