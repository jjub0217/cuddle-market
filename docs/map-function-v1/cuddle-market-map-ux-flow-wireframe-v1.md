# 📄 커들마켓 지도 기반 생활 서비스 유저 플로우 및 화면 구조서 (v1.0)

---

## 1. 문서 목적

본 문서는 커들마켓의 지도 기반 생활 서비스 기능 개발을 위해  
사용자 흐름, 화면 구조, 주요 인터랙션 정책을 정의하는 것을 목적으로 한다.

이 문서는 프론트엔드/백엔드/디자인 팀이 다음 내용을 공통으로 이해하도록 돕는다.

- 사용자가 어떤 흐름으로 기능을 사용하는지
- 화면이 어떤 구조로 구성되는지
- 지도, 필터, 상세정보가 어떤 방식으로 동작하는지
- 디바이스별(데스크탑/모바일) UI 차이가 무엇인지

---

## 2. 지도 진입 정책

### 2-1. 최초 진입 기준

- 지도 첫 진입 시 사용자의 **현재 위치 권한을 요청**한다.
- 사용자가 위치 권한을 허용하면 현재 위치를 기준으로 지도 중심을 설정한다.
- 사용자가 위치 권한을 거부하거나 위치를 가져올 수 없는 경우, **기본 위치는 서울 시청 (위도: 37.5666, 경도: 126.9784)**으로 설정한다.
- 최초 진입 시 기본 카테고리는 **동물병원**이 선택된 상태로 표시한다.

### 2-2. fallback 정책

다음 경우에는 기본 위치(서울 시청)로 진입한다.

- 사용자가 위치 권한 요청을 거부한 경우
- 브라우저/디바이스에서 위치 정보를 가져오지 못한 경우
- 위치 정보 요청 시간이 초과된 경우
- 기타 예외 상황으로 현재 위치 확인이 실패한 경우

### 2-3. 사용자 안내

- 위치 권한이 허용되지 않은 경우, 사용자에게 현재 위치 기반 탐색이 제한된다는 안내 문구를 노출할 수 있다.
- 단, 서비스 이용 자체는 가능해야 하며 기본 위치(서울 시청) 기준 탐색이 가능해야 한다.

## 3. 카테고리 전환 정책

### 3-1. 카테고리 UI

- 지도 화면 상단에 **탭 버튼 형태**로 카테고리를 배치한다.
- 사용자는 상단 탭을 눌러 카테고리를 전환할 수 있다.

### 3-2. 카테고리 목록

- 동물병원
- 카페
- 식당
- 숙소

### 3-3. 카테고리 전환 시 동작

- 선택한 카테고리에 해당하는 장소 데이터만 지도에 표시한다.
- 지도 중심 위치는 유지한다.
- 카테고리 전용 필터는 해당 카테고리에 맞게 변경한다.
- 이전 카테고리의 전용 필터는 초기화하거나 비활성화 정책을 별도로 정의해야 한다.
  - 현재 초안 기준: **카테고리 전환 시 해당 카테고리 전용 필터만 활성화**
  - 공통 필터 외 이전 카테고리 전용 필터는 유지하지 않음

## 4. 상세 정보 노출 정책

### 4-1. 마커 클릭 시 상세정보 노출 방식

#### 데스크탑

- 사용자가 마커를 클릭하면 **오른쪽 사이드바**에서 상세 내용을 표시한다.

#### 모바일

- 사용자가 마커를 클릭하면 **하단 슬라이드 카드 UI**로 상세 내용을 표시한다.

### 4-2. 상세정보 공통 항목

- 장소명
- 카테고리
- 주소
- 연락처
- 운영시간
- 대표 이미지(있는 경우)
- 추천 여부
- 리뷰 요약
- 리뷰 목록 보기
- 리뷰 작성 버튼
- 네이버 지도앱 연결 버튼 (길찾기 대체)

### 4-3. 카테고리별 상세정보 예시

#### 동물병원

- 24시간 운영 여부
- 응급 진료 가능 여부
- 특수동물 진료 가능 여부
- 진료 가능 동물 종류

#### 카페 / 식당 / 숙소

- 추천 장소 여부
- 이용 가능 조건(추후 확장 가능)
- 네이버 지도앱 연결 버튼 (길찾기 대체)

## 5. 주요 사용자 플로우

---

## 5-1. 공통 진입 플로우

1. 사용자가 지도 서비스 화면에 진입한다.
2. 시스템이 위치 권한을 요청한다.
3. 사용자가 위치 권한을 허용하면 현재 위치 기준으로 지도를 보여준다.
4. 사용자가 위치 권한을 거부하거나 실패하면 서울 시청을 기본 위치로 보여준다.
5. 기본 카테고리(동물병원)가 선택된 상태로 주변 동물병원 마커가 표시된다.
6. 상단 카테고리 탭에서 원하는 카테고리로 전환할 수 있다.

---

## 5-2. 동물병원 찾기 플로우

1. 사용자가 지도 화면에 진입한다.
2. 상단 탭에서 **동물병원**을 선택한다.
3. 지도에 주변 동물병원이 표시된다.
4. 사용자가 병원 전용 필터를 선택한다.
   - 24시간 운영
   - 응급 진료 가능
   - 특수동물 진료 가능
5. 지도 결과가 필터 조건에 맞게 갱신된다.
6. 사용자가 특정 병원 마커를 클릭한다.
7. 상세 정보가 표시된다.
   - 데스크탑: 오른쪽 사이드바
   - 모바일: 하단 슬라이드 카드
8. 사용자는 리뷰를 확인하거나 리뷰를 작성할 수 있다.
9. 네이버 지도앱 연결 버튼을 통해 길찾기를 할 수 있다.

---

## 5-3. 카페 찾기 플로우

1. 사용자가 상단 탭에서 **카페**를 선택한다.
2. 반려동물 동반 가능 카페가 지도에 표시된다.
3. 추천 카페가 별도 표시되거나 강조 표시된다.
4. 사용자가 마커를 클릭한다.
5. 상세 정보와 리뷰를 확인한다.
6. 사용자는 리뷰를 작성할 수 있다.
7. 네이버 지도앱 연결 버튼을 통해 길찾기를 할 수 있다.

---

## 6. 필터 구조

### 6-1. 공통 필터

- 카테고리 탭 선택
- 추천 장소 보기 여부(추후 확정 필요)

### 6-2. 동물병원 전용 필터

- 24시간 운영
- 응급 진료 가능
- 특수동물 진료 가능
  - 파충류
  - 조류
  - 기타 확장 가능

### 6-3. 카페 / 식당 / 숙소

- 별도 전용 필터 없음 (반려동물 동반 가능 장소만 노출되므로 필터 불필요)

### 6-4. 필터 적용 방식

- 지도 내 UI에서 즉시 선택 가능해야 한다.
- 사용자가 필터를 누르면 지도 결과가 갱신된다.
- 데스크탑/모바일 모두 빠른 필터 접근이 가능해야 한다.

## 7. 추천 장소 노출 정책

- 추천 장소는 일반 장소와 구분되어야 한다.
- 추천 장소는 광고 상품화 가능성을 고려해 별도의 뱃지 또는 강조 UI를 제공한다.
- 추천 장소는 각 카테고리별로 존재할 수 있다.
  - 추천 동물병원
  - 추천 카페
  - 추천 식당
  - 추천 숙소

---

## 8. 예외 상황 정책 초안

### 8-1. 위치 권한 거부

- 서울 시청 기본 화면 진입
- 현재 위치를 사용할 수 없다는 안내 가능

### 8-2. 검색 결과 없음

- 지도 위 결과가 없음을 알리는 UI 노출
- 필터 해제 또는 다른 카테고리 선택 유도

### 8-3. 상세 정보 부족

- 운영시간, 전화번호, 이미지 등 일부 정보가 없는 경우 빈 상태 UI 또는 기본 문구 표시

### 8-4. 리뷰 없음

- "아직 작성된 리뷰가 없습니다" 문구 표시
- 첫 리뷰 작성 유도

## 9. 화면 구조

---

## 9-1. 데스크탑 화면 구조

### 기본 레이아웃

- 상단: 카테고리 탭
- 지도 영역: 메인 콘텐츠
- 우측: 상세정보 사이드바
- 지도 위: 필터 버튼 영역

### 구성 예시

1. 상단 카테고리 탭
   - 동물병원
   - 카페
   - 식당
   - 숙소

2. 지도 내 필터 버튼
   - 24시
   - 응급
   - 파충류
   - 조류
   - 추천

3. 지도 마커
   - 일반 장소
   - 추천 장소(구분 UI)

4. 우측 상세 사이드바
   - 장소명
   - 카테고리
   - 주소
   - 연락처
   - 운영시간
   - 추가 정보
   - 리뷰 목록
   - 리뷰 작성 버튼
   - 네이버 지도앱 연결 버튼

---

## 9-2. 모바일 화면 구조

### 기본 레이아웃

- 상단: 카테고리 탭
- 중앙: 지도
- 지도 위/아래: 필터 버튼
- 하단: 마커 선택 시 슬라이드 카드

### 구성 예시

1. 상단 카테고리 탭
2. 지도
3. 필터 버튼 영역
4. 마커 클릭 시 하단 슬라이드 카드
   - 장소명
   - 카테고리
   - 주소
   - 운영시간
   - 추천 여부
   - 리뷰 보기 / 리뷰 작성
   - 네이버 지도앱 연결 버튼
   - 상세보기 또는 확장 가능 UI

## 10-1. 데스크탑 와이어프레임

│ [24시] [응급] [파충류] [조류] [추천]          │ 상세정보 영역 │
│                                               │               │
│                                               │ 장소명        │
│                 지도 영역                      │ 주소          │
│               (마커 표시)                      │ 운영시간      │
│                                               │ 연락처        │
│                                               │ 리뷰 목록     │

│                                               │ 네이버 지도   │
│                                               │               │
├───────────────────────────────────────────────┴───────────────┤
│ 하단 보조 정보 영역(선택사항)                                  │
└───────────────────────────────────────────────────────────────┘
