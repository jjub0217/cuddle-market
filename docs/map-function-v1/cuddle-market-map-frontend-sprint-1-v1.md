## 5. 필요한 API 스펙

### 장소 목록 조회

GET /api/places

필수 필드:

- id
- name
- latitude
- longitude
- isRecommended
- reviewSummary

### 장소 상세 조회

GET /api/places/{placeId}

필수 필드:

- id, name, address, phone, operatingHours, imageUrl
- latitude, longitude (네이버 지도앱 딥링크용)
- isRecommended
- reviewSummary
- detail (병원: is24Hours, isEmergencyAvailable, animalTypes)
