**"더 이상 반려동물 용품은 한 번 쓰고 버리는 물건이 아닙니다."**

아이처럼 빠르게 성장하는 우리 반려동물들. <br/>
금세 작아진 옷, 흥미를 잃은 장난감, 한두 번 쓴 캐리어... <br/>
집 한구석에 쌓여가는 용품들을 보며 아까운 마음이 드셨나요? <br/>

**CUDDLE MARKET**은 반려동물을 사랑하는 모든 가족들이 모여
따뜻한 마음을 나누는 동네 시장입니다.
